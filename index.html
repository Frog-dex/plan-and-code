Try it in 60 seconds

Serve the folder (python3 -m http.server 8080), open the blueprint, then:

  1. ✥ Plan — click the hero on the demo page to track it.
  2. Drag the gold dashed box somewhere new, or nudge it with the arrow keys.
  3. ◉ Animate — draw a motion path on the stage, add a spec, hit ▶ preview.
  4. ⧉ Copy AI HANDOFF and paste it into your coding agent with the spec.

What the AI receives

A readable diff, then the raw JSON. The contract lives in docs/BLUEPRINT-README.md.

# SITE BLUEPRINT — AI HANDOFF (v2)
Site: ./demo/index.html · viewport 1045x828

## hero  (#hero)  · view:default
existing: left 0.0% · top 6.2% · w 100.0% · h 31.2%
PLANNED:  left 0% · top 6.5% · w 100% · h 42%
- NOTE: make the hero taller, image behind the title
- ANIMATION "rise-in": trigger=power-on duration=900ms
  easing=ease-out — title floats up and settles
  motion-path (viewport %): [[50,40],[50,33],[50,30]]

## RAW JSON (authoritative)
{"version":2,"site":"./demo/index.html", …}
Existing — where the element really is in the live code right now.
Planned — where you dragged it. The AI makes this real in the element’s own CSS system.
Motion path — a hand-drawn trajectory in viewport %, attached to an animation spec.
✎Notes — one instruction per line. The AI is told to honor every one.
